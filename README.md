# 📖 如我所书 — 昔涟的文字冒险游戏插件

翻开这本名为「你」的书，在星空下写一段只属于你的冒险。无论是独自前行，还是与伙伴并肩，故事都从这里开始。

一款由 AI 主持的 AstrBot 文字冒险游戏插件：所有指令以「冒险」开头。轻规则 RPG 属性作为叙事锚点，内置 22 个种族/职业图鉴模板一键套用，GM 在结果真实不确定时掷**真实随机 d20 判定骰**，冒险结束后自动**结算成长与结局**，并在 AstrBot 官方面板提供 WebUI 管理台。

---

## 🚀 快速上手

1. `冒险 创建角色 阿涟 一名喜欢在星夜旅行的见习魔法师` —— 生成角色卡
2. `冒险 种族列表` / `冒险 职业列表` —— 从图鉴挑模板，`冒险 种族 精灵`、`冒险 职业 法师` 一键套用补正与被动
3. `冒险 开始` —— 翻开第一页（可加 `世界:世界名` 与自定义主题）
4. 直接输入你的行动，或从 GM 给出的 A/B/C 选项中选择（群体冒险用 `冒险 投票 A`）
5. 临时离开时输入「暂停」保存进度，之后 `冒险 继续` 随时接上；超时也会自动暂停
6. 主动输入「退出/结束」结束冒险，用 `冒险 结局` 查看收集到的结局卡

## 🎭 角色卡系统

### 创建与查看

| 指令 | 说明 |
|:-----|:------|
| `冒险 创建角色 <名字> <描述>` | 自主创建角色卡，末尾可加 `于<世界名>` 关联世界观 |
| `冒险 修改角色 <新描述>` | 更新角色描述 |
| `冒险 修改角色 添加社会地位 <身份>` | 设置角色在该世界中的社会身份 |
| `冒险 修改角色 关联世界 <世界名>` | 变更所属世界观 |
| `冒险 随机角色 [世界名]` | LLM 随机生成角色卡（含属性/种族/职业/能力） |
| `冒险 保存随机角色 <名字>` | 随机角色改名保存 |
| `冒险 我的角色` | 查看角色卡 |
| `冒险 属性` | 查看完整属性面板 |

### 三维属性

| 属性 | 说明 | 范围 |
|:-----|:------|:------|
| **力量/体魄** | 作为近身、负重、抗压等叙事判定锚点 | 1~1000 |
| **敏捷/反应** | 作为闪避、先手、移动等叙事判定锚点 | 1~1000 |
| **精神/意志** | 作为专注、法术、污染抗性等叙事判定锚点 | 1~1000 |

| 指令 | 说明 |
|:-----|:------|
| `冒险 设置属性 <力量> <敏捷> <精神>` | 修改三维（仅首次冒险前） |
| `冒险 重置属性` | 回退到默认值（魅力/幸运不变） |

**创建规则：**
- 自主创建：三维之和 ≤ 30，单项 ≥ 3（管理员不限）
- 随机生成：单项 1~20，随机角色严格锁定不可手动改属性（v1.4.0 修复了旧版可绕过的缺陷），只能改名保存

### 魅力 & 幸运

创建时随机生成（F~A+），终身不可修改。以 F~S 评级表示，影响战力计算和冒险中的隐藏判定。

| 评级 | 系数 |
|:-----|:----:|
| S | 2.20 |
| A+ | 1.85 |
| A | 1.70 |
| B | 1.30 |
| C | 1.00 |
| D | 0.85 |
| E | 0.70 |
| F | 0.50 |

### 实力阶层

内部仍保留战力数值，作为强弱锚点，避免出现"路边杂兵打成Boss"或"幕后Boss早期被普通攻击击败"的情况；对外主要展示阶层，降低数值焦虑。

```
战力 = (力量×0.4 + 敏捷×0.3 + 精神×0.3) × 魅力幸运平均评级系数
```

| 阶层 | 战力范围 | 说明 |
|:-----|:----:|:------|
| 普通人 | 0~20 | 日常危险与低威胁敌人 |
| 训练者 | 21~50 | 能处理普通杂兵，但不宜硬抗精英 |
| 精英 | 51~150 | 明显强于常人 |
| 超凡 | 151~500 | 可稳定压制低阶敌人 |
| 灾厄级 | 501~999 | 低阶角色正面对抗几乎必败 |
| 神话级 | 1000~9998 | 需要同阶、克制或剧情条件 |
| 神明级 | 9999 | 不可战胜锚点，默认不可被击败 |

### HP & MP

HP/MP 暂时作为状态参考，不进行复杂机械扣血扣蓝。属性变更时仍会自动重算，供叙事判断使用。

### 种族 & 职业

v1.4.0 起内置**种族/职业图鉴库**：22 个模板——10 种族（人类/精灵/矮人/兽人/半身人/龙裔/亡灵/侏儒/半精灵/兽化人）与 12 职业（战士/法师/游侠/盗贼/牧师/圣骑士/德鲁伊/吟游诗人/武僧/狂战士/猎魔人/学者），首次启动自动播种到 `archetypes.json`。

| 指令 | 说明 |
|:-----|:------|
| `冒险 种族 <名称>` | 设置种族：命中图鉴自动套模板；未命中按自定义记录（零补正）并提示 |
| `冒险 职业 <名称>` | 设置职业：命中图鉴自动套模板；未命中按自定义记录（零补正）并提示 |
| `冒险 种族列表` | 浏览种族图鉴（三维补正、天赋被动/负面） |
| `冒险 职业列表` | 浏览职业图鉴（三维补正、专属技能） |

- 种族模板提供三维补正（-2~+3）与天赋被动，部分附带负面特质；职业模板提供三维补正与不占主动技能格的专属技能
- 命中图鉴时补正**立即生效**并重算战力阶层；图鉴条目（含内置模板）可在 WebUI「世界与图鉴」页增删改查
- 随机角色生成与冒险结算提取获得的种族/职业，名称命中图鉴时同样自动套模板

### 能力标签

技能系统已轻量化为"能力标签"：用于帮助 GM 判断角色能做什么、能做到什么程度，而不是完整的数值战斗引擎。

| 类型 | 上限 | 说明 |
|:-----|:----:|:------|
| **主动能力** | 3 个 | 需要主动使用的能力、招式或专长 |
| **被动特质** | 3 个 | 常驻生效的天赋、体质或背景特征 |

| 指令 | 说明 |
|:-----|:------|
| `冒险 技能 主动 <名称> <描述>` | 记录主动能力 |
| `冒险 技能 被动 <名称> <描述>` | 记录被动特质 |
| `冒险 技能 遗忘 <名称>` | 删除不再需要的能力 |
| `冒险 栏位` | 查看能力栏位概况（`冒险 技能点` 为别名） |

能力成长由冒险经历与结算结果体现，没有 MP 消耗、等级和技能点等复杂机制。

### 冒险锁定机制

完成 **第一次冒险** 后（`has_adventured = true`），非管理员角色卡属性将被锁定：

- ❌ 不可手动修改三维属性
- ❌ 不可重置属性
- ✅ 可通过结算提取**永久性**提升属性
- ✅ 可遗忘能力标签
- ✅ 结算中获得的新能力、种族、职业变更可写入角色卡，继承到下次冒险

## 🎲 判定骰与结算

### 判定骰（GM 自主判定）

v1.3.0 新玩法，**全程无需任何指令**：

- 插件每回合向 GM 注入 3 个**真实随机 d20 骰值**（插件侧掷骰，避免 LLM 自造随机数），每个骰值只用一次，仅对当前回合有效
- GM 仅在行动结果**真实不确定**时判定：常规成功、明显失败、纯对话都不掷骰
- 骰值叠加角色倾向锚点与世界强度差后，参考映射为：1~5 不利（失败/大失败）、6~10 惜败或付出代价、11~15 险胜、16~18 成功、19~20 大成功
- 判定结果自然融入叙述，最多在句中简短标注（如：判定：敏捷 d20=14 → 险胜），不会罗列数值表

不想掷骰？在配置中关闭 `enable_dice_judgment` 即可回到纯叙事判定。

### 结算提取

冒险**结束、暂停或超时自动暂停**时，LLM 会作为结算官从本轮经历中提取并写回：

- **防重复（v1.4.0）**：提取带水位线，只结算上次之后新增的剧情——同一冒险多次暂停/继续/超时不会重复提取
- **三维属性永久成长**：每项 ≤ +2、合计 ≤ +3，仅当叙事中有明确成长依据
- **新能力**：最多 2 条主动/被动能力标签
- **种族/职业变更**：冒险中明确获得或变更时写回角色卡，名称命中图鉴时自动套用模板
- **结局卡**：称号（≤20字）、摘要（≤60字）与 1~3 个标签，存入个人结局图鉴；**仅在主动输入「退出/结束」时写入**，暂停/超时只提取成长、不算结局
- **世界书沉淀**：关键 NPC、地点、伏笔、世界规则写入该世界的条目（每次最多 2 条）

提取失败会静默跳过，不影响正常结算；可用配置 `enable_settle_extract` 关闭（关闭后每次结算少消耗一次 LLM 调用）。

## 🌍 世界观与世界书

| 指令 | 说明 |
|:-----|:------|
| `冒险 投稿世界观 <名称> <设定>` | 投稿新世界观 |
| `冒险 世界观列表` | 浏览所有世界观 |
| `冒险 世界观 <名称>` | 查看世界观详情与彩蛋 |

- 世界书条目（关键 NPC、地点、伏笔、世界规则）在**冒险开局与进行中的每个回合**都会按关键词匹配注入上下文（v1.4.0 起回合中提到关键词也会命中；同一冒险中每条目只注入一次），受 `lore_content_budget` 字符预算约束
- 结算提取沉淀的新条目会自动追加到对应世界（每次最多 2 条，世界总量上限 200 条）
- 世界观可设置尺度档位（凡人/超凡/神话）与实力参考，让"新手村的木棍"和"仙界的神兵"真正不同
- 世界观与条目的编辑、彩蛋管理推荐使用 WebUI 管理台

## 🎮 冒险系统

### 单人冒险

| 指令 | 说明 |
|:-----|:------|
| `冒险 开始 [世界:名] [主题]` | 开始单人冒险 |
| `冒险 退出` | 退出并结算 |
| `冒险 日志` | 查看最近的冒险记录 |
| `冒险 帮助` | 显示帮助 |

- 冒险进行中直接输入行动即可，GM 给出 2~3 个选项供参考，也欢迎自由探索
- 明语指令：输入 `暂停` 或 `存档` 保存退出；输入 `退出` 或 `结束` 结束冒险
- 每回合超过 `single_timeout` 秒未行动，冒险会**自动暂停保存**（v1.3.0 起不再直接结束），`冒险 继续` 接上

### 群体冒险

| 指令 | 说明 |
|:-----|:------|
| `冒险 开始 群体 [世界:名] [主题]` | 在群聊中开启群体冒险 |
| `冒险 加入` | 加入当前群体冒险 |
| `冒险 投票 <A/B/C/自定义行动>` | 本轮投票，截止前可改票 |
| `冒险 状态` | 查看群体冒险状态 |
| `冒险 退出` | 从冒险中退场 |

- 每轮投票限时 `group_round_time` 秒；全员投完会提前进入下一轮，平票时发起者的票优先
- 每轮可为部分玩家生成个性化线索，上限 `group_max_clues_per_round` 条（0 关闭）
- 中途加入者会在下一轮以合理方式登场；退场后不能再次加入同一场冒险，全员退场即结束
- 最后一人退场时自动收官（v1.4.0）：写入群体日志、全员标记首次冒险完成，并逐人结算提取（受 `enable_settle_extract` 约束）

### 存档

| 指令 | 说明 |
|:-----|:------|
| `冒险 存档` | 查看存档列表（按最近更新排序） |
| `冒险 继续 <序号>` | 继续指定存档（缺省为最近一份） |
| `冒险 放弃 <序号>` | 删除指定存档 |

存档保留 LLM 原文历史与冒险摘要，继续时从上次进度无缝接上。

## 🖥️ WebUI 管理台

v1.3.0 起 WebUI 迁移到 AstrBot 官方插件页面机制：在 **AstrBot 面板的插件卡片**中打开「如我所书」页面即可，无需单独部署，鉴权由面板负责。

**功能一览：**
- 世界与图鉴管理（v1.4.0）：页内三段切换——世界观 / 种族库 / 职业库，图鉴条目（含内置模板）可增删改查
- 角色卡 / 存档管理（增删改查）
- Chara Card V3 JSON 导入导出、PNG 角色卡导入
- 插件配置编辑（与插件配置页等效，`kb_name` 等在页面或插件配置页均可修改，保存立即生效）
- 渲染脚本编辑：正则替换冒险文本的显示效果，带测试预览

**实时同步：** 在聊天里投稿世界观、创建/修改角色、设置属性、变更种族/职业/能力标签、存档增删或完成结算，页面会在几秒内自动出现变化；在页面里保存的内容也立即对聊天生效。

**渲染脚本说明：** 只处理发给用户的显示副本，聊天历史与存档始终保留 LLM 原文。

## ⚙️ 配置

| 参数 | 默认值 | 说明 |
|:-----|:------:|:------|
| `kb_name` | 如我所书 | 关联知识库名称。角色卡和世界观在创建/投稿时自动写入该知识库作备份（只写不读）；留空停用 |
| `default_theme` | 奇幻世界 | 未指定主题时的默认冒险主题 |
| `lore_content_budget` | 4000 | 单次冒险上下文中世界书条目内容的最大字符数 |
| `single_timeout` | 300 | 单人冒险每回合行动超时（秒），超时自动暂停并保存 |
| `group_round_time` | 120 | 群体冒险每轮投票等待（秒） |
| `group_max_players` | 8 | 群体冒险人数上限 |
| `group_max_clues_per_round` | 2 | 群体冒险每轮个性化线索条数上限（每条一次 LLM 调用，0 关闭） |
| `enable_dice_judgment` | true | 启用判定骰（真实随机 d20）；关闭后回到纯叙事判定 |
| `enable_settle_extract` | true | 启用结算提取；关闭后不提取成长/结局/世界书沉淀 |

## ❓ 常见问题

**Q：完成一次冒险后属性改不了了？**
A：这是首次冒险锁定机制。三维属性不再允许手动修改或重置，成长来自结算提取的永久加点（有叙事依据才会加点），能力标签仍可自由遗忘。

**Q：随机角色能改属性吗？**
A：不能。随机角色的属性由 LLM 掷定（单项 1~20），v1.4.0 起严格锁定（修复了旧版可绕过的缺陷），只能用 `冒险 保存随机角色 <名字>` 改名保存后开始冒险。

**Q：我设置的种族/职业怎么没有补正？**
A：名称未命中图鉴时按自定义记录（零补正）。用 `冒险 种族列表` / `冒险 职业列表` 查看内置模板后重新设置，或在 WebUI「世界与图鉴」页把自定义种族/职业添加进图鉴库。

**Q：知识库备份是做什么的？**
A：`kb_name` 指定的知识库只作为角色卡与世界观的**只写备份**，冒险并不读取它。需要在 AstrBot 面板的知识库页面创建同名知识库才会生效，留空可停用自动入库。

**Q：不想要判定骰或结算提取？**
A：在插件配置（或 WebUI 配置页）把 `enable_dice_judgment` / `enable_settle_extract` 设为 false。关闭判定骰后 GM 回到纯叙事判定；关闭结算提取后不再产出结局卡与世界书沉淀。

**Q：渲染脚本会影响存档内容吗？**
A：不会。渲染脚本只替换发到聊天里的显示文本，历史、存档与结算提取读取的始终是 LLM 原文。

## 🛠️ 开发者注记

1. **写文件统一走 `core._save_json`**（临时文件原子替换，含 `_ensure_within_data_dir` 数据目录防穿越校验）；读取走 `_load_json`（损坏文件自动备份为 `.corrupt.*`），不要绕开直接 open/json.dump。
2. **所有保存/导入入口先归一化再落盘**：复用 `normalize_world` / `normalize_character`（内部调用 `sync_world_eggs`），不要手工拼数据结构。
3. **世界书条目 id 由 `lore._new_entry_id` 生成**（`uuid4().hex`）；条目去重按名称，世界书条目总量上限 200。
4. **LLM 原文只进 history 与存档**；发给用户的副本经 `main._render_story` → `render_pipeline.apply_render_scripts` 做正则渲染，两条通路不可混用。
5. **向后兼容约束**：`web_api._normalize_legacy_world` 的 `plot_nodes` 兼容分支仍在被现网数据使用，不可移除；世界 `content` → `entries` 的迁移逻辑同理。`normalize_character` 会剥离 `skill_points` / `attr_locked` / `mp_cost` 等遗留字段。
6. **`settle.SETTLE_EXTRACT_PROMPT` 含字面花括号**（JSON 示例），拼接输入时禁止 `str.format()`，只能字符串相加；结算约束常量（属性钳制、条目上限等）都在 `settle.py`。
7. **测试为纯函数测试**：`python -m pytest -q` 运行 `test_lore_mvp.py` / `test_chara_card_v3.py` / `test_render_pipeline.py` / `test_settle.py` / `test_archetypes.py`，涉及 LLM 与落盘的逻辑由 `main.py` 承担，不在测试覆盖范围内。
8. **图鉴文件即真相**：`archetypes.seed_builtin_archetypes` 只在 `archetypes.json` 为空时播种内置模板，不合并、不重复播种；角色 `race`/`job` 字段须由 `archetypes.archetype_to_char_field` 生成以兼容 `_recalc_rpg` 消费格式；结算提取拼接提示词同样禁止 `str.format()`。
